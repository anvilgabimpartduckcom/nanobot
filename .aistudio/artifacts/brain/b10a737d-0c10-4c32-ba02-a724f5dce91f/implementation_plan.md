# nanobot Feature Upgrade & Architecture Refinement Plan

Comprehensive blueprint implementing all 8 requested features: About nanobot documentation, Old UI scale restoration, file reader code-output isolation, Cloudflare R2 older chat tiering, Sign Up modal button restructuring, email confirmation redirect auto-detection, input visibility rules, and Tavily URL scraping.

---

## User Review & Critical Decisions

> [!IMPORTANT]
> - **UI Scale Restoration**: Header buttons, main serif title, composer box, and send/upload controls will be upscaled to match `nanobot.html` and the 'Old UI' reference screenshot.
> - **File Reader & Storage Strategy**:
>   - Raw files / images are isolated to browser `localStorage` under `nanobot_local_files_<chatId>`.
>   - Cloud-persisted chat records (Supabase / R2) will back up **only the code output** generated by the script analyzer, not bulky binary files.
>   - Deleting a chat deletes both the cloud record and the local files from `localStorage`.
> - **Cloudflare R2 Tiered Storage**:
>   - **Supabase**: Authentication, user profiles, conversation list, and recent active messages.
>   - **Cloudflare R2**: Older conversation archives stored as encrypted JSON blobs.
> - **Sign Up Modal Fix**:
>   - The large redundant button is removed.
>   - In its place, the secondary action becomes the primary button: **"Resend Confirmation Email"**, which triggers a fresh verification link.
> - **Email Confirmation Redirect Handling**:
>   - On app startup, the root component detects Supabase verification hashes (`#access_token=...&type=signup`) and active sessions, automatically opening the modal in **Step 2** with the confirmed email prefilled.
> - **Field Visibility Rules**:
>   - **Account Creation**: Password, OpenRouter Key, and Tavily Key are visible as plain text (`type="text"`).
>   - **Sign In**: Password is masked (`type="password"`).
> - **Tavily URL Scraper Tool**:
>   - The model can emit `<Scrap1>URL1</Scrap1> <Scrap2>URL2</Scrap2>` to extract full web page markdown using Tavily's `extract` endpoint (`https://api.tavily.com/extract`), displaying `"Scraping Web Pages..."` during execution.

### 3. File Storage & Code-Output Backup
- Raw files / images are stored in `localStorage` under `nanobot_files_<chatId>`.
- In `ChatMessage`, the content saved to the database contains only the text prompt and the generated Python script code output:
  `[Analyzed File: <filename>] Output:\n<code_output>`.
- The raw `image_url` data URLs are not transmitted to Supabase or R2.
- Deleting a chat cleans up both the remote record and `localStorage.removeItem('nanobot_files_' + chatId)`.

### 4. Cloudflare R2 Setup & Tiered Archiving
- Create `src/lib/r2.ts` implementing S3-compatible REST calls (PUT/GET/DELETE) to Cloudflare R2 bucket:
  `https://<R2_ACCOUNT_ID>.r2.cloudflarestorage.com/<R2_BUCKET_NAME>/<chatId>.json`.
- Recent messages (< 10 messages) remain in Supabase `public.chats`.
- Older messages are archived into Cloudflare R2.
- Document environment variables in `.env.example` and `README.md`.

### 5. Sign Up Pop-Up Refinement
In `AuthModal.tsx`:
- When email confirmation link is dispatched:
  - Remove the large green "I've Confirmed in My Inbox →" button.
  - Position the "Resend Confirmation Email" button in its place as the primary action.
  - Clicking it invokes `supabase.auth.signInWithOtp` to send another email.

### 6. Email Confirmation Redirect Auto-Detection
- In `src/App.tsx`, listen on mount for URL hash (`#access_token=...&type=signup`) and `supabase.auth.onAuthStateChange`.
- If a user opens the confirmation link in a new tab, the app automatically:
  1. Captures the verified email from the session (`session.user.email`).
  2. Opens `AuthModal` in `signup` mode at **Step 2**.
  3. Displays: Username, Password, OpenRouter Key, Tavily Key, and "Create Account".

### 7. Input Visibility Rules
- **Sign Up (Step 2)**:
  - Password input: `type="text"` (visible while creating account).
  - OpenRouter API Key input: `type="text"` (visible).
  - Tavily API Key input: `type="text"` (visible).
- **Sign In**:
  - Password input: `type="password"` (masked).

### 8. Tavily URL Scraping Tool
- Implement `extractUrlsWithTavily(urls: string[], apiKey: string)` in `src/lib/tavily.ts` calling `https://api.tavily.com/extract`.
- In `src/App.tsx`, update system prompt to inform the model about the scraping capability:
  - Can be called on first turn or after search.
  - Model emits `<Scrap1>URL1</Scrap1> <Scrap2>URL2</Scrap2>`.
  - While scraping, UI displays `"Scraping Web Pages..."`.
  - Content returned is injected into the context.
