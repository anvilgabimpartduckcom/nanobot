## Love using nanobot? I'd love to hear from you!

Reach out to me:

1. To show your love for nanobot, get technical help, and details, or sharing your new ideas about nanobot, join the [GitHub discussion](https://github.com/anvilgabimpartduckcom/nanobot/discussions/2).

2. For reporting errors, or bugs, create an issue, and follow the below given format:
```format
Title: A suitable title reflecting the error
Device: (Choose between Mobile/PC) (Required)
Error: (A detailed description of the error you'd like to report or the problem you are facing) (Required)
Probable solution: A probable solution that you think might just work (Optional)
Visual: Attach pictures (Optional, but helpful, if possible)
```

3. For personalized replies, (OR, if you don't have a GitHub account but still want to contribute) email at **molecule-sip-sauna@duck.com**. If you need to attach any files to it, do not attach any other kind of files except text files (.txt) and image files (any extension, .jpg, .png, etc).

Note: A lot of times Duck Mail is marked as spam and put into the spam folder. So make sure to check the spam folder regularly if you can't find my reply!

### Warning: I NEVER merge any pull requests created by any user, as it might lead to unintended user data compromise. So, please don't create any.
